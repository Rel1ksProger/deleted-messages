# DeletedMessages — плагин для exteraGram

Плагин для exteraGram, который сохраняет удалённые сообщения в локальный кеш и позволяет просматривать их в текущем чате. Работает на **Python** через официальный Plugin SDK exteraGram (Chaquopy). Совместим с **exteraGram 13.1.1** и выше.

---

## ✨ Возможности

- 📋 **Просмотр удалённых сообщений** текущего чата в нативном BottomSheet.
- 👤 **Информация о каждом сообщении**: отправитель, время удаления (ЧЧ:ММ:СС), тип медиа (текст, фото, видео, аудио, документ, стикер) и краткий фрагмент текста.
- 🔔 **Уведомление при удалении** (опционально) — нативный Bulletin exteraGram/Telegram вместо системного Toast.
- ✕ **Удаление отдельной записи** из кеша прямо из BottomSheet.
- 🗑 **Очистка кеша**: только для текущего чата или полностью (при выгрузке плагина).
- ⚙️ **Настройка лимита** сообщений на чат (от 10 до 1000, по умолчанию 100).
- 🔄 **Автоматическая упаковка `.plugin`** через GitHub Actions при каждом пуше в `main`.

---

## 📋 Требования

- **exteraGram** версии **13.1.1** или новее (рекомендуется последняя стабильная сборка).
- Включённый **движок плагинов** и **режим разработчика** в настройках клиента.
- Для установки из файла: возможность открывать `.plugin` / `.py` файлы в exteraGram (обычно включена по умолчанию).

> Плагин **не требует** установки на устройстве собеседника — кеш ведётся локально.

## 🚀 Установка


1. **Скачайте файл плагина**  
   Возьмите `deleted_messages.plugin` из раздела **Releases** GitHub-репозитория (или из артефакта, созданного GitHub Actions).  
  
2. **Включите движок плагинов в exteraGram**  
   Откройте **exteraGram → Настройки (Preferences) → Плагины** и активируйте переключатель **«Движок плагинов»**.  
   Затем откройте информационный экран плагинов и включите **«Режим разработчика»** (Developer Mode)[reference:0][reference:1].

3. **Откройте скачанный файл**  
   Нажмите на файл `.plugin` (или `.py`) в файловом менеджере или в чате Telegram. exteraGram сам покажет окно установки[reference:2].

4. **Подтвердите установку**  
   Нажмите **«Установить»** и, если предложено, **«Включить после установки»**[reference:3].  
   Если клиент запросит разрешение на установку из неизвестного источника — разрешите (плагин не из официального каталога).

5. **Проверьте работу**  
   После установки в списке плагинов появится карточка **«Deleted Messages»**. Убедитесь, что переключатель активен.  
   Откройте любой чат → меню (⋮) → **«Удалённые сообщения»** — должен открыться BottomSheet (пока пустой, если удалений ещё не было).
